# Niyukt

Niyukt is a two-sided platform connecting people who need physical tasks or inspections performed at a location with eligible taskers who execute those tasks and submit structured evidence.

## V1 Domain

Verified vehicle inspection.

## Stack

- React
- Node.js
- Express
- MongoDB

## Primary Engineering Focus

Backend engineering, system design, authorization, state-driven workflows, testing, performance, security, Docker, and deployment.
